# Read a USD stage

- Drag in the 3D view to orbit, right-drag or Shift+drag to pan, use the wheel to zoom. Double-click or F fits the model.
- W shows the polygon edges, S hides the shaded surfaces. The up axis comes from the file's upAxis.
- Click a prim in the tree to highlight its meshes and list its attributes, relationships, references, payloads and variant sets. Double-click a prim to frame it.
- USDA text opens a read-only text tab of the layer. For a USDC file that is the binary layer written out as text.
- In a USDZ package, Files lists every file in the archive with its size and alignment.
