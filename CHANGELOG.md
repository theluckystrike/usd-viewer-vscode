# Changelog

## 0.1.0

- First release. Opens .usda, .usdc, .usd and .usdz files in a VS Code editor tab.
- Prim tree with types, references, variants and inactive prims marked, a filter box, and the details of the selected prim.
- USDC binary layers shown as USDA text in a read-only tab, in the layout the USD tools write.
- 3D view of meshes and the simple shapes (cube, sphere, cylinder, cone, capsule, plane) and point instancers, with orbit, pan, zoom, wireframe and a highlight of the selected prim.
- Follows sublayers, references, payloads, inherits and the selected variants, on disk and inside USDZ packages.
- Syntax colors for .usda files.
- Zovo Pro tools: Convert and export, Stage check, Compare two USD files (3 free tries each).
